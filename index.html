🧠 La fórmula para detectar el fraude

No memorices párrafos. Busca estas 4 pistas: CANAL + EMOCIÓN + SEÑAL + ACCIÓN.

📨

1. CANAL

¿Llegó por correo, SMS, WhatsApp o llamada?

😨

2. EMOCIÓN

¿Intentan provocarte miedo, urgencia o intimidación?

🚩

3. SEÑAL

¿Piden claves, tokens, datos o transferencias?

🛑

4. ACCIÓN

Detén la interacción y aplica la regla correcta.

🎣 PHISHING

📧 CORREO😨 MIEDO🚫 CERO CLICS

🔎 ¿Qué ocurre?

El delincuente envía un correo que aparenta ser de una institución confiable y busca llevar a la víctima a una página falsa para obtener sus credenciales.

Ejemplo: “Detectamos una transacción sospechosa. Ingresa al portal de seguridad para cancelarla”.
🚩 SEÑALES DE ALERTA
  • Remitente con letras o dominios extraños.
  • Enlace para iniciar sesión.
  • Solicitud de claves o datos sensibles.
🛑 REGLA: CERO CLICS. No ingreses tus claves desde enlaces recibidos por correo.

📱 SMISHING

📲 SMS / WHATSAPP⚡ URGENCIA🗑️ BORRAR Y BLOQUEAR

🔎 ¿Qué ocurre?

Es el phishing adaptado a mensajes móviles. Busca que actúes rápido aprovechando la urgencia, curiosidad o miedo a perder un servicio.

Ejemplo: “Tu Token Digital ha caducado. Evita la suspensión ingresando aquí”.
🚩 SEÑALES DE ALERTA
  • Enlaces acortados o extraños.
  • Mensaje inesperado con presión de tiempo.
  • Solicitud de claves, tokens o datos de tarjeta.
🛑 REGLA: BORRAR Y BLOQUEAR. No abras enlaces sospechosos.

🎭 SPOOFING

📞 IDENTIDAD FALSA😌 FALSA SEGURIDAD📵 CUELGA

🔎 ¿Qué ocurre?

El delincuente falsifica o manipula la identidad que aparece en tu teléfono o navegador para parecer una fuente legítima.

Ejemplo: La pantalla muestra “Interbank” y el supuesto operador pide tu Token para “validar” una operación.
🚩 SEÑAL DE ALERTA

Te solicitan dictar Token, Clave Dinámica, CVV o Clave Web.

🛑 REGLA: EL TOKEN NO SE DICTA A NADIE. Si te lo piden, CUELGA.

📞 VISHING

🗣️ VOZ😱 INTIMIDACIÓN☎️ CORTA

🔎 ¿Qué ocurre?

La estafa ocurre durante una llamada. El delincuente usa autoridad, presión y un discurso convincente para manipular a la víctima.

Ejemplo: “Su cuenta está siendo vulnerada. Transfiera su dinero a una cuenta de resguardo”.
🚩 SEÑALES DE ALERTA
  • Te piden transferir dinero para “protegerlo”.
  • Usan amenazas o cargos de autoridad.
  • Te presionan para no colgar.
🛑 REGLA: CORTA LA LLAMADA. Nunca transfieras dinero a una cuenta desconocida para “protegerlo”.
